🌍 Project Overview
This project replicates the core user interface of Netflix. The primary goal was to achieve a "Pixel-Perfect" look while ensuring the layout is fully responsive across various device sizes—from mobile phones to ultra-wide desktop monitors.

🚀 Key Features
Responsive Navigation: A sticky, transparent-to-solid navigation bar that adapts to scroll position.

Hero Section: A captivating main banner with stylized buttons, mimicking the signature Netflix "Play" and "More Info" UI.

Movie Grids: Organized, scrollable sections with hover animations that provide a seamless browsing experience.

Modern CSS: Utilization of Flexbox and CSS Grid for complex layouts and perfect alignment.

Cross-Platform Compatibility: Designed to look consistent on Chrome, Firefox, Safari, and Edge.

🛠 Tech Stack
Markup: HTML5 (Semantic Tags)

Styling: CSS3 (Flexbox, Grid, Media Queries, Transitions)

Version Control: Git & GitHub
